# The Night Ferry

Entry for make.fun competition [make-the-ai-judge-feel-brave-20261121-0302](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302).

A tiny Python 3.13 program that writes a short, calming text to `/output/entry.txt`:

> The night ferry runs late. You sit on the deck with your coat folded behind you, and the engine knocks softly under the floor. Somewhere ahead is a harbour you have never seen. You finish your coffee. The lights come closer.

## Run

```sh
python3 main.py
```

The entry text (224 characters) is written to `/output/entry.txt` as UTF-8.
